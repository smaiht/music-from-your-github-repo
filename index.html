    How a tree becomes music

    An “amplitude over time” picture is all you need to make a sound, but play the tree’s silhouette directly as a waveform and you get clicks and hum. So the tree drives notes inside a musical frame instead: each section has its own chords, the peaks of the silhouette sing the melody, the other lines play the accompaniment, and the loudness of the silhouette decides how many instruments join in.

    Tree propertyWhat you hearHow it’s computed
    Line number, top to bottomTime, left to rightOne line = one grid step. The rate is picked so the track lasts between 20 seconds and 3 minutes.
    Top-level folderSong sectionEach section gets its own 4-bar chord progression from a tried-and-tested set and its own lead instrument. Long sections follow an A A B A form. Files in the root close with a cadence to the tonic.
    Silhouette peaksMelodyIn each half-bar the line with the longest name sings. The higher the silhouette, the higher the note, so the melody’s rhythm follows the shape of the tree.
    Other linesAccompanimentA soft arpeggio over the current chord. Each note’s volume depends on the name’s length, and the pattern restarts in every new folder.
    Folder nameMotifA short melodic figure that repeats while the folder’s files play. Stepping into a subfolder raises the melody, stepping out lowers it. On strong beats the note is pulled to a chord tone.
    Silhouette over 4-bar phrasesArrangementFour levels: intro, groove, full band, climax. Quiet stretches play without drums, loud ones add drums, bass and doublings.
    File typeTimbreA section plays the instrument of its main file type. A file of another type adds a quiet ornament on its own instrument.
    Letter densityNote brightnessThe share of inked pixels in each character, relative to the densest ASCII character. “iii” sounds darker, “WWW” brighter.
    File sizeNote lengthLog of the size: big files ring on, small ones are short and clipped.
    Position among siblingsStereoThe first file in a folder sits on the left, the last on the right.
    Dominant languageModePython is Dorian, JavaScript Mixolydian, TypeScript Lydian, Go and Java major, Rust and C minor, C++ Phrygian.
    Repository nameKeyA hash of the name picks one of 12 tonics. The same repo in the same style always sounds the same.
    Median name lengthTempoShort names give a faster tempo, long ones slow it down, within the style’s tempo range.

    Section instruments in the current style

      Guitar, electric piano, vibraphone, kalimba, marimba and bells are synthesised in the browser from a model of a vibrating string or bar: every overtone decays at its own rate. The drums are built like those of the 808 and 909 drum machines. Effects depend on the style: plate reverb, ping-pong delay, chorus, electric-piano tremolo, kick sidechain, tape with pitch wobble, vinyl crackle, saturation, EQ, compressor and limiter. Open the MIDI file in any DAW to re-voice it with your own instruments.

      Filophone GitHub trees come from the public API. The built-in examples are saved ahead of time and work offline.
